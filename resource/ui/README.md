# UI 贴图定制（人工补图）

本目录保存**手工修改过的界面贴图源**。这些不是从汉化包提取的原始素材（那些由 `script/extract_patch.py` 重新生成，不入库），而是我们额外补做的美术修正。

## 清单

| 文件 | 内容 |
|------|------|
| `config02_chip.png` | 设置界面「声音停止设定」一行，补入原素材缺失的「下一语音」按钮文字 |

`config02_chip.png` 是 **无损 RGBA 源**：`np.asarray(Image.open(...).convert('RGBA')).tobytes()` 与游戏用的裸 RGBA 数据逐字节一致（1480×1494，8844480 字节），可直接用 `tool/pb3.py` 编码进 `data/image/update/`。

## 背景

汉化组提供的 `config02_chip.pb3` 中，`自动读取` 与 `文字渐隐` 之间的格子是**空白**（对应原版 `Next Voice`）。这是汉化组素材本身的缺口，不是编码问题。

## 生成方式

该图**由人眼判读 + 参数化合成**得到，不是启发式自动生成。一次性脚本按约定不保留，完整复现步骤见 `doc/engine-mechanics.md` §12。

## 关键参数（定稿 v29）

几何基准（实测，图集与实机 1:1，无缩放）：

| 项 | 值 |
|----|-----|
| 图幅 | 1480×1494，RGBA |
| 四列格子左沿 | 4 / 138 / 272 / 406 |
| 参考行（`自动读取`）字迹顶 | y = 1321 |
| 行距 | 42（补图落到 y = 1363） |
| 格内左内边距 | 25 |
| 墨迹框 | 75×18 |

合成参数：

| 项 | 值 |
|----|-----|
| 字体 | `C:\Windows\Fonts\simsun.ttc`（宋体） |
| 字号 | 20，**直接渲染，不缩放** |
| 描边 | 无（`stroke_width=0`） |
| 覆盖率 gamma | 0.35 |
| 字芯色 | col0 `(97,97,97)` / col1 col2 `(255,255,255)` / col3 `(172,172,172)` |
| 发光适用列 | 仅 col1 / col2（**暗列不加发光**） |
| 发光强度 amp | 150 |
| 衰减 tau | 2.8 px（指数衰减 `amp·exp(-d/τ)`，d = 到字芯的欧氏距离） |
| 色相 | 近处暖 `(1.00,0.97,0.84)` → 远处冷 `(0.25,0.10,-0.45)` |
| 淡出 | `clip((11-d)/4, 0, 1)` |

## 验收数据（相对底板的径向亮度剖面，d1..d5）

只统计金列（暗列不参与发光统计），底板取该行最左/最右 4 列采样：

| 列 | 来源 | d1 | d2 | d3 | d4 | d5 | 字芯 px |
|----|------|----|----|----|----|----|---------|
| col2 | 原图 `自动读取` | 58.0 | 34.0 | 13.0 | -6.0 | -1.0 | 1504 |
| col2 | 补图 `下一语音` | 48.3 | 33.0 | 12.1 | -6.7 | -0.2 | 1431 |
| col1 | 原图 `自动读取` | 37.0 | 53.0 | 44.0 | 35.0 | 14.0 | 1238 |
| col1 | 补图 `下一语音` | 28.8 | 33.5 | 31.5 | 12.2 | -8.2 | 1513 |

`d4` 出现负值是原图自带的「内侧高光 + 外侧压暗」结构，不是误差。

## 复现要点

1. 用 `extract_patch.py` 从汉化包抽出 `config02_chip.pb3` 的裸 RGBA。
2. 按上表在四列 `y=1363` 处合成「下一语音」。
3. `tool/pb3.py` 编码后写入 `data/image/update/config02_chip.pb3`。
4. **必须保留原 alpha 通道**：这张图有 39% 的像素 alpha≠255，整图 `convert('RGB')` 再转回会把滑条/输入框/勾选框糊成白块。
